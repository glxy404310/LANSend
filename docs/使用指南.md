# LANSend 桌面版

## 安装和升级

- Windows 10/11：常见 Intel / AMD 电脑选 Windows x64 包。解压后双击 **LANSend.exe**，在图形提示中选择安装。以后从开始菜单打开 LANSend。无需管理员权限。若已有旧版，等传输结束后再升级，原配对和收件箱会自动沿用。
- Mac：解压后把 **LANSend.app** 拖进“应用程序”，双击打开。首次启动会配置本机接收器和 Finder 快速操作。支持 Apple 芯片与 Intel Mac。安装包使用本地签名，未做 Apple 公证；Windows 包未做开发者分发签名。
- 从旧版升级至 v1.7.0 及以上版本后，原有配对记录和收件箱会自动沿用，但需在两台电脑上打开「配对与设置 → 已配对设备 → 管理…」，检查原设备是否已勾选启用（未启用时无法收发文件，也不会生成对应右键菜单项）。
- 使用局域网模式时，两台电脑需要连接允许设备互访的网络。首次启动时，为接收程序允许受信任网络上的入站连接。

## 收发文件

在“文件传输”点“选择文件并发送”，可一次选多个文件发送给当前发送目标（可在设备管理中设置，每次传输发给一台设备）。Windows 还可把文件拖到主窗口。发送完成后，接收端可在前台收件窗口选择文件，再点“打开文件”或“打开收件夹”，也可在主窗口点“打开收件箱”。

Windows 资源管理器右键 →（显示更多选项）→ 发送到 → **LANSend · 设备名称**，会直接打开图形进度窗口并发送给该设备，无需先切换主窗口的发送目标。Mac Finder 右键 → 快速操作或服务 → **LANSend · 设备名称** 同样直接指定接收设备。每个已启用设备都会自动生成对应菜单项；设置备注后会显示备注名，停用或取消配对后会自动移除。系统同时保留「用 LANSend 发送」入口用于发给当前发送目标（从旧版升级时会自动清理原有的「发送到 Mac」/「发送到 Windows」入口）。关闭主窗口后，接收器继续在当前用户登录期间运行。更新双方后可直接选择或拖入文件夹，接收端保留目录结构（含空目录）。文件夹作为一个队列项发送，含符号链接或特殊文件时会提示失败。点「重试失败项」只会重新发送失败的项。

## 新设备配对与多设备管理

LANSend 支持同时配对多台电脑。在一台电脑的「配对与设置」点击「复制 LANSend 码」，在另一台电脑复制这串码并点击「从剪贴板配对」（有效期 5 分钟，两端均需使用支持 LANSend 码的版本）。新配对会直接加入设备列表，不会覆盖已有设备。配对完成后，需在两台电脑的「配对与设置 → 已配对设备 → 管理…」中分别勾选启用对方并保存，之后才能互传文件。首页右上角显示「已连接 N 台设备」，统计已启用且当前可达的设备（局域网与 Tailscale 远程连接均纳入统计，同一台设备只计一次）。

在「配对与设置 → 已配对设备 → 管理…」中，可统一管理所有已配对电脑：
- **启用 / 停用**：勾选启用后允许与该设备收发文件并生成「LANSend · 设备名称」右键菜单；取消勾选即停用，保留配对记录和备注，同时移除对应右键菜单项（若停用当前发送目标，会自动切换到其他已启用设备）。
- **备注**：为设备单独设置本机备注，菜单和界面会优先显示备注名；清空备注即可恢复对方的设备名称。
- **发送目标**：在已启用的设备中点击「设为发送目标」，指定主窗口和「用 LANSend 发送」的默认接收设备。
- **取消配对**：移除该设备的配对记录及其右键菜单项。

默认收件位置为 Mac 的 `~/Downloads/LANSend` 或 Windows 的 `%USERPROFILE%\Downloads\LANSend`，可在“配对与设置”的“收件目录”中选择其他可写文件夹或恢复默认位置（对后续新收到的文件即时生效，无需重启）。重名会自动编号。在「配对与设置」可按需修改本机名称并保存，对方会看到新名称。局域网地址变化后，LANSend 使用 UDP 53318 广播查找设备，并核对原配对证书。网络需允许广播和设备互访；文件传输使用 TCP 53318。在“配对与设置”可选择前台弹窗或静默接收。静默模式只保存文件，重启后仍然生效。

## 不同网络之间传文件

在需要互传的两台电脑（Windows 与 Windows、Mac 与 Mac，或 Windows 与 Mac）上各安装一份 LANSend。远程功能使用内置的 Tailscale tsnet 节点，局域网模式可独立使用，无需安装系统 VPN 客户端。

1. 两台电脑都使用 LANSend 1.5 或更新版本，打开 **我的电脑 → 远程连接**。首次使用时，在浏览器里用同一个 Tailscale 账号授权。已用 1.4 登录的设备会沿用已有身份。
2. 保持两端在线，在任意一台的 **我的电脑** 页等几秒。列表会自动更新，并结合对方主机名（或 Tailscale 自定义设备名）与平台短标识展示以便区分。如果只有一台候选电脑，会默认选中；如果有多台，请选择目标设备。点击 **配对所选电脑** 一次，两端都会保存配对。
3. 在两台电脑的 **配对与设置 → 已配对设备 → 管理…** 中勾选启用对方后，即可通过主窗口或「LANSend · 设备名称」右键菜单发送。已有同一设备的局域网地址会保留；新增其他电脑时不会替换已有配对。
4. 列表仅显示同一账号拥有、在线且使用 LANSend 内置远程连接的电脑。另一台也需完成授权。企业网络如启用了设备审批或访问规则，请批准两台 LANSend 节点并允许它们互访 TCP 53318。同一私人网络中的其他账号、共享设备和标签设备不会参与自动配对。
5. 纯局域网配对或添加其他局域网电脑时，仍可在 **配对与设置** 页使用 LANSend 码；切换默认接收设备则在设备管理中设置发送目标。异地时，接收电脑需要开机、登录并保持唤醒。

身份密钥保存在当前用户 LANSend 配置目录的 tsnet 子目录，请保留在对应电脑上。可在 Tailscale 管理后台移除设备授权。远程模式在首次点击后启用，纯局域网用户无需登录。

## 卸载

Mac 在终端执行 `launchctl bootout "gui/$(id -u)/local.lansend.receiver"`，然后删除 LANSend 主应用、`~/Library/LaunchAgents/local.lansend.receiver.plist`、`~/Library/Services/` 下的 `LANSend · *.workflow` 与 `用 LANSend 发送.workflow`（如曾使用旧版，也检查是否残留 `发送到 Windows.workflow`）和 `~/Library/Application Support/LANSend`。
Windows 关闭 LANSend，在任务管理器结束安装目录下的 receiver.exe，再删除开始菜单 LANSend、`shell:startup` 下的 LANSend Receiver、`shell:sendto` 下的“LANSend · 设备名称”与“用 LANSend 发送”（如曾使用旧版，也检查是否残留“发送到 Mac”），以及 `%LOCALAPPDATA%\LANSend` 和 `%APPDATA%\LANSend`。从旧版升级的设备可能保留通知注册项 `HKCU\Software\Classes\lansend-reveal` 和 `HKCU\Software\Classes\AppUserModelId\LANSend.Receipts`。配对目录中含本机身份私钥。已经接收的文件单独保存在收件箱。

## 校验下载

从同一 Release 下载 SHA256SUMS.txt。macOS 在 ZIP 所在目录运行 `shasum -a 256 LANSend-macOS-universal.zip`。Windows 在 PowerShell 运行 `Get-FileHash .\LANSend-Windows-x64.zip -Algorithm SHA256`。将输出与清单中同名文件的值核对。
