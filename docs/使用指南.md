# LANSend 桌面版

## 安装和升级

- Windows 10/11：常见 Intel / AMD 电脑选 Windows x64 包，ARM 电脑选 Windows ARM64 包。解压后双击 **LANSend.exe**，在图形提示中选择安装。以后从开始菜单打开 LANSend。无需管理员权限。若已有旧版，等传输结束后再升级，原配对和收件箱会自动沿用。
- Mac：解压后把 **LANSend.app** 拖进“应用程序”，双击打开。首次启动会配置本机接收器和 Finder 快速操作。支持 Apple 芯片与 Intel Mac。安装包使用本地签名，未做 Apple 公证；Windows 包未做开发者分发签名。
- 使用局域网模式时，两台电脑需要连接允许设备互访的网络。首次启动时，为接收程序允许受信任网络上的入站连接。

## 收发文件

在“文件传输”点“选择文件并发送”，可一次选多个文件。Windows 还可把文件拖到主窗口。发送完成后，接收端可点击通知定位到文件，也可在主窗口点“打开收件箱”。

Windows 资源管理器右键 →（显示更多选项）→ 发送到 → 发送到 Mac，会直接打开图形进度窗口。Mac Finder 右键 → 快速操作或服务 → 发送到 Windows。关闭主窗口后，接收器继续在当前用户登录期间运行。文件夹请先压缩再发送。

## 新设备配对

已配对时，窗口顶部显示保存的目标地址。使用手动配对时，在两台电脑上打开“设备配对”，分别填写**另一台**的局域网地址及 12 位校验码，点击“验证并保存配对”。程序使用 HTTPS，并仅接受配对证书的文件。配对地址发生变化时，在此更新即可。

收件位置为 Mac 的 `~/Downloads/LANSend` 或 Windows 的 `%USERPROFILE%\Downloads\LANSend`。重名会自动编号。默认接收端口为 TCP 53318。看不到通知时，在系统通知设置中启用 LANSend 的通知和横幅。

## 不同网络之间传文件

Windows 与 Mac 各安装一份 LANSend。远程功能使用内置的 Tailscale tsnet 节点，局域网模式可独立使用，无需安装系统 VPN 客户端。

1. Windows 和 Mac 都升级到 LANSend 1.5 或更新版本，打开 **我的电脑 → 远程连接**。首次使用时，在浏览器里用同一个 Tailscale 账号授权。已用 1.4 登录的设备会沿用已有身份。
2. 保持两端在线，在任意一台的 **我的电脑** 页等几秒。列表会自动更新。如果只有一台候选电脑，会默认选中；如果有多台，请选择目标设备。点击 **配对所选电脑** 一次，两端都会保存配对。
3. 现在可以从任意一端右键发送。已有同一设备的局域网地址会保留。连接过另一台电脑时，手动配对页可用于明确更换目标设备。
4. 列表仅显示同一账号拥有、在线且使用 LANSend 内置远程连接的电脑。另一台也需完成授权。企业网络如启用了设备审批或访问规则，请批准两台 LANSend 节点并允许它们互访 TCP 53318。同一私人网络中的其他账号、共享设备和标签设备不会参与自动配对。
5. 纯局域网或需要更换目标时，仍可在 **设备配对** 页输入对方地址与 12 位校验码。异地时，接收电脑需要开机、登录并保持唤醒。

身份密钥保存在当前用户 LANSend 配置目录的 tsnet 子目录，请保留在对应电脑上。可在 Tailscale 管理后台移除设备授权。远程模式在首次点击后启用，纯局域网用户无需登录。

## 卸载

Mac 在终端执行 `launchctl bootout "gui/$(id -u)/local.lansend.receiver"`，然后删除 LANSend 主应用、`~/Library/LaunchAgents/local.lansend.receiver.plist`、`~/Library/Services/发送到 Windows.workflow` 和 `~/Library/Application Support/LANSend`。
Windows 关闭 LANSend，在任务管理器结束安装目录下的 receiver.exe，再删除开始菜单 LANSend、`shell:startup` 下的 LANSend Receiver、`shell:sendto` 下的“发送到 Mac”，以及 `%LOCALAPPDATA%\LANSend` 和 `%APPDATA%\LANSend`。通知注册项为 `HKCU\Software\Classes\lansend-reveal` 和 `HKCU\Software\Classes\AppUserModelId\LANSend.Receipts`。配对目录中含本机身份私钥。已经接收的文件单独保存在收件箱。
